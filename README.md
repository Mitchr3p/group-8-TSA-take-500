# planet (Git demo)

The skeleton everyone starts from. It has two sections from the Figma: the **header** and the **hero** (search bar + planet card). HTML and CSS only.

| Section | HTML goes in `index.html` between | CSS file |
|---------|-----------------------------------|----------|
| Header  | `<!-- HEADER -->` and `<!-- END HEADER -->` | `css/header.css` |
| Hero    | `<!-- HERO -->` and `<!-- END HERO -->`     | `css/hero.css` |

- `css/base.css`: the colours, fonts and reset. Only the captain or vice captain edits it.
- `images/`: the logo, icons and Earth picture.
- `copy-code/`: the finished code for the demo, ready to copy and paste.

## The one naming rule

**Every class starts with your section's name, then a dash, then the thing.**

```
header-logo      header-toggle
hero-card-name   hero-search-button
```

## Run it

Open `index.html` in the browser, or use **Live Server** in VS Code.
